**- Descripcción:**  
Programa que se ejecuta en la consola, este permite un gestor simple 
de personajes con siertos atrivutos como su nombre, una arma, habilidades y poder.
Tambien permite el registro de peleas entre estos con fecha incluida.


**- ¿Como se podria ejecutar?**  
Ya que este prorama solo se ejecuta en consola yo diria que 
instalen un IDE a gusto que sea capaz de manejar java y que copien
y peguen el repositorio tal cual esta dispuesto.


**- Funcionalidades:**
- menu de 8 opciones (una de estas siendo salir).
- capacidad para ingresar al menos 20 personajes distintos.
